# Docker Workspace Dashboard

Расширение для VS Code, которое предоставляет простую панель управления Docker: контейнеры, образы и тома доступны прямо в редакторе.

## Возможности

- Просмотр всех контейнеров (включая остановленные) с деталями по логам, inspect и статистике.
- Быстрые действия: запуск, остановка, рестарт, удаление контейнера и `docker exec` в новый терминал VS Code.
- Просмотр Docker образов с вкладками Inspect/History и удаление ненужных образов.
- Просмотр Docker томов, доступ к Inspect и удаление томов.
- Команда палитры **Docker: Show Active Containers** для быстрого списка только запущенных контейнеров.
- Локализация интерфейса (ru/en) с автоматическим выбором по языку VS Code и переключателем внутри панели.
- Индивидуальный скролл для каждого списка, ручной ресайз колонок «список ↔ детали» и селектор масштаба (70–100%).
- Кнопка подгрузки дополнительных логов прямо в панели деталей контейнера.

## Быстрый старт

1. Установить зависимости:
   ```bash
   npm install
   ```
2. Собрать проект:
   ```bash
   npm run compile
   ```
3. Запустить режим разработки: откройте вкладку Run and Debug и запустите конфигурацию **Run Extension** (`F5`).
4. Во втором окне (Extension Development Host) используйте команду **Docker: Open Container Dashboard**.

## Рабочий процесс команды

- Репозиторий инициализирован веткой `development`. Создавайте фичи в отдельных ветках от неё и оформляйте pull request'ы обратно в `development`.
- Перед пушем выполняйте `npm run compile` — TypeScript должен собираться без ошибок.
- Добавляйте пользовательские сценарии в `README` или `docs/`, чтобы команда понимала новые возможности панели.
- При доработках UI держите логику в `media/dashboard.html`, а взаимодействие с Docker — в `src/extension.ts`.

## Команды npm

| Скрипт            | Назначение                              |
|-------------------|-----------------------------------------|
| `npm run compile` | Одноразовая сборка TypeScript → `dist/` |
| `npm run watch`   | Вотчер TypeScript для локальной разработки |
| `npm run lint`    | Заглушка, можно расширить под ESLint    |

## Требования

- Docker CLI должен быть установлен и доступен в `PATH`.
- VS Code ≥ 1.85 (указано в `package.json`).
- Node.js ≥ 18 (для работы текущей конфигурации TypeScript).

Если Docker требует повышенных прав, убедитесь, что расширение запускается в окружении, где CLI доступен без sudo.
